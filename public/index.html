Unsupervised Anomaly Detection Tool for Shearographic Image Analysis

Bachelor thesis: Development of a computer vision pipeline that automatically identifies, localizes, and visualizes structural anomalies in images by utilizing the unsupervised learning algorithm RD++. The entire pipeline was specifically validated and tested on a shearographic dataset.

KanjiReader: Mobile App for Automatic Japanese Text Recognition and Translation

Team project: Development of a mobile application for the automated recognition and translation of Japanese text in images using React Native and Expo. The app can also automatically add furigana to Japanese text. I was responsible for implementing the OCR functionality for detecting and extracting Japanese text from images.
